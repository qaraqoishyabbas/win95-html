# Базовый рабочий стол Windows 95

Пользователь утвердил локальную версию 21 ноября 2026 года. Сохраняем HTML, обычный JavaScript, Tailwind и стиль Windows 95. Данные остаются в браузере, без сервера и аккаунтов.

## Согласованное поведение
- Проводник: настоящие папки, переходы назад/вверх, создание текстов и папок, переименование, копирование, вырезание, вставка, удаление и свойства.
- Блокнот: автосохранение, меню, поиск/замена, импорт и скачивание UTF-8 .txt, выделение текста, перенос строк.
- Окна: изменение размеров, разворачивание и восстановление, фокус, клавиатурное переключение.
- Пуск: программы, документы, настройки, справка, завершение работы с возможностью вернуться.
- Калькулятор: арифметика, память, проценты, клавиатура, копирование/вставка числа, справка.
- Корзина: восстановление дерева папки в прежнее расположение или на рабочий стол, окончательное удаление, очистка с подтверждением.
- Надёжность: Delete не удаляет файл при вводе текста; миграция старых документов и корзины; корректная работа на узких экранах; понятная ошибка при невозможности сохранения.

## Подход
Выбрано развитие существующей локальной версии. Сервер с аккаунтами и синхронизацией отложен как отдельный объём. Одна модель файлов для рабочего стола и проводника; отдельные модули хранения, калькулятора и интерфейса. Старые ключи localStorage сохраняются как резервная копия. Новая модель сохраняется одним атомарным setItem; при ошибке операция отменяется.

## Решения реализации
Системные папки защищены от удаления, обычные документы и папки изменяемы. Один выбор файла за раз, внутренний буфер обмена файлов; системный буфер используется для текста с обработкой отказа. Завершение работы действует внутри страницы. Для меню и диалогов используем HTML, сохраняем доступ с клавиатуры. На узких экранах окна ограничиваются доступной областью.

## Приёмка
Автотесты модели покрывают миграцию, рекурсивные операции, коллизии имён, циклический перенос, восстановление и отказ хранилища. Проверки браузера покрывают полный цикл документа, папки, меню, окна, клавиатуру, перезагрузку и мобильный экран. Проверяем сборку CSS и синтаксис всех скриптов.
