# Win95 Desktop

Локальный рабочий стол Windows 95 на HTML, JavaScript и Tailwind CSS 4. Без серверной базы данных и аккаунтов.

## Запуск

Требуются Node.js с npm и Python 3.

```sh
npm install
npm run build:css
npm start
```

Откройте http://127.0.0.1:4173. Во время изменения стилей можно запустить `npm run watch:css` в другом терминале. JavaScript не требует сборки. Иконки и скрипты используют относительные пути, поэтому сайт можно разместить в подпапке статического хостинга.

## Публикация на Netlify

```sh
npm run build
```

Сборка создаёт готовую папку `site/` с HTML, скомпилированным CSS, скриптами и иконками. Относительные пути сохраняются, в том числе `dist/output.css` внутри папки публикации.

- **Build command:** `npm run build`
- **Publish directory:** `site`
- **Base directory:** пусто (корень проекта)

Эти настройки также записаны в `netlify.toml`. При публикации через Git добавьте изменения сборки в репозиторий и запустите новый deploy. При ручной загрузке сначала выполните сборку и загрузите папку `site/` в Netlify.

## Возможности

- Рабочий стол: выделение, перетаскивание, сохранение координат, упорядочивание и контекстное меню.
- Проводник: диск C:, системные и пользовательские папки, переходы назад/вверх, значки/список, создание, переименование, копирование, вырезание, вставка и свойства.
- Блокнот: автосохранение, история отмены/повтора в открытом окне, поиск, замена всех совпадений, текстовый буфер обмена, выбор переноса строк и размера шрифта, импорт UTF-8 `.txt` до 2 МБ, скачивание и сохранение копии.
- Корзина: удаление папок вместе с содержимым, восстановление, восстановление всех, подтверждение окончательного удаления и очистки. Если исходная папка недоступна, объект восстанавливается на рабочий стол.
- Калькулятор: арифметика, повторное равенство, проценты, корень, обратное число, память, копирование/вставка числа и клавиатура.
- Окна: фокус, перетаскивание, сворачивание, изменение размера за нижний правый угол, разворачивание и восстановление. Размер также меняется стрелками при фокусе на нижнем правом углу.
- Меню «Пуск»: программы, последние документы, настройки цвета/шрифта/часов, справка и завершение работы виртуального компьютера.

## Клавиатура

| Клавиши | Действие |
| --- | --- |
| Enter | Открыть выбранный объект |
| Стрелки | Выбрать следующий/предыдущий значок |
| F2 / Delete | Переименовать / переместить в корзину |
| Ctrl/⌘ + C, X, V | Копировать, вырезать, вставить файл или текст |
| Ctrl/⌘ + N / Shift + N | Новый документ / папка |
| Ctrl/⌘ + O | Импортировать `.txt` |
| Ctrl/⌘ + S / Shift + S | Сохранить / скачать текст Блокнота |
| Ctrl/⌘ + F, H / F3 | Найти, заменить / следующее совпадение |
| Ctrl/⌘ + Z / Shift + Z | Отменить / повторить в Блокноте |
| Ctrl + Tab | Переключить окно внутри страницы |
| Alt + F4 | Закрыть окно, если сочетание передано браузером странице |
| Shift + F10 | Открыть контекстное меню |
| F1 / Esc | Справка / закрыть меню |
| Калькулятор: Enter, Esc, Backspace, F9 | Результат, сброс, удалить цифру, сменить знак |

Стандартные сочетания клавиш могут перехватываться браузером или ОС. Для всех операций доступны экранные команды. В меню работают стрелки, Home, End, Enter и Esc. Delete внутри редактора редактирует текст.

## Хранение

Данные сохраняются в `localStorage` текущего адреса сайта (`win95_filesystem_v2`). Старые ключи документов и корзины автоматически переносятся и остаются резервной копией. Новая структура записывается целиком одной операцией; при ошибке операция отменяется. Если автосохранение текста не удалось, текст остаётся в окне: его можно скачать. Закрытие и удаление такого документа защищены от потери последних изменений.

Изменение данных в другой вкладке требует перезагрузки перед новой записью: устаревшая вкладка не перезаписывает новые документы. При повреждённых данных сайт предлагает скачать JSON-копию исходного локального хранилища и не сбрасывает его автоматически.

Данные принадлежат конкретному браузеру и адресу сайта. Очистка данных сайта удаляет их. Для важных текстов используйте скачивание `.txt`. Файловый буфер обмена действует внутри страницы; текстовый использует системный буфер, при запрете браузера предлагает поле для ручной вставки.

## Проверки

```sh
npm test
npm run test:browser
```

Браузерные тесты используют установленный Google Chrome через Playwright. Они сами запускают локальный HTTP-сервер на порту 4173. Проверяют жизненный цикл документов и папок, миграцию и перезагрузку, корзину, клавиатуру, настройки, поиск/замену, импорт/скачивание, окна и узкий экран, отказ и повреждение хранилища.

Исходники: `src/filesystem.js` — модель и хранение, `src/calculator.js` — вычисления, `src/app.js` — интерфейс, `src/input.css` — стили.
